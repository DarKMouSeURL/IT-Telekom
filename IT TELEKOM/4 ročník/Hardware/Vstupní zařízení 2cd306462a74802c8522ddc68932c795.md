# Vstupní zařízení

- hardware, kterým se pořizují data
- součást uživatelského rozhraní

# Rozdělení

1. **textové vstupní zařízení**
    1. klávesnice
2. **zařízení s ukazatelem**
    1. myš
    2. trackball, trackpoint
    3. touchpad
    4. haptická rukavice
    5. 3D polohovací zařízení
    6. světelné pero
    7. doteková rukavice
    8. grafický tablet
3. **herní zařízení**
    1. joystick
    2. gamepad
    3. volant + pedály
4. **zařízení snímající obraz a zvuk**
    1. Scanner

    4. rozpoznání řeči

# Klávesnice

- od psacího stroje
- pro vkládání znaků a ovládání PC
- různé rozložení kláves
    - qwertz, qwerty, azerty
- přípojení přes USB
    - starší PS2, DIN

# Trackball

- kulička na podložce
- dává se u informačních center
- také pro lidi s postižením
    - dysfunkce motoriky
- není vhodné pro hry
