## definice malware, typy malware a jejich popis

- malicious software (škodlivý software)
- není jednotná definice
- jakýkoli software k narušení standardní činností PC systému, zisk informací (dat), či využitá k získání přístupu k PC systému

## obecné členění kybernetických útoků +

- **viry**
    - propojují se s jiným souborem
- **červy**
    - samostatný program, šíří se bez zásahu uživatele
- **trojské koně**
    - přetvarují se jako legimitivní program
- **Ransomware**
    - zašifruje data na PC/celá síť, vymáhání výkupného
- **ostatní**
    - **exploity**
        - využití chyby systému
    - **rootkity**
        - získání a držení přístupu, tajně
    - **adware**
        - zobrazují reklamy
    - **spyware**
        - tajně shromažďuje údaje

## popis základních typů útoků

- sociální inženýrství
- DOS/DDOS
    - botnet
- SQL injection
- UDP flood
- ICMP flood
- SYN flood

### Man in the middle

- ARP spoofing
- DNS spoofing
- Session hijacking
- HTTPS spoofing
