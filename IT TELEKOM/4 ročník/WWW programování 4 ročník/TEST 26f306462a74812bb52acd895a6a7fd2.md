# TEST

### **1. Vysvětlete pojem JavaScript a o jaké skriptování se jedná?**

- high level language
- interpretovaný
- pro dynamické webové stránky
- klientovské skriptování (spouští se v klientově prohlížeči) i vzdáleně na serveru NODE.JS
- Syntaxně podobný C/C++/Java

### **2. Uveďte protiklad tohoto typu skriptování.**

- PHP, spuštěn vzdáleně na serveru

### **3. Vyjmenujte charakteristiky jazyka JavaScript.**

- **Interpretovaný:** Není potřeba kompilovat, prohlížeč vykonává přímo.
- **Na straně klienta (Client-side):** Hlavní exekuční prostředí je webový prohlížeč.
- **Dynamický:** kontrolují za běhu a není nutné je explicitně deklarovat.
- **Objektově orientované**
- **Integrovaný s DOM a BOM:** Umožňuje manipulovat s obsahem stránky (DOM), oknem prohlížeče a jeho vlastnostmi (BOM).

### **4. K čemu lze JavaScript použít?**

- **Webové stránky:** Dynamická změna obsahu, animace, validace formulářů, reakce na události uživatele
- **Webové aplikace:** Aplikace jako Gmail, Google Maps nebo Facebook využívají JS
- **Serverové aplikace:** Pomocí prostředí **Node.js** lze JavaScript spouštět na serveru.

### **5. Jaká jsou omezení JavaScriptu?**

- **Závislost na prohlížeči uživatele:** Různé prohlížeče a jejich verze mohou JS interpretovat mírně odlišně, i když moderní standardy tento problém minimalizují.
- Je pomalejší než kompilované jazyky
- Nemá typovou kontrolu

### **6. Záleží u JavaScriptu na velikosti písma?**

Ano, je **case-sensitive**

### **7. Jakými způsoby lze začlenit skript do stránky? (uveďte jednotlivé způsoby).**

1. **Vložený (inline) skript pomocí tagu `<script>`:** Kód se píše přímo do HTML souboru.
    
    ```html
    <script>
        alert('Ahoj světe!');
    </script>
    
    ```
    
2. **Externí skript pomocí atributu `src`:** Kód se načte z externího souboru.
    
    ```jsx
    <script src="muj-script.js"></script>
    
    // nový soubor muj-script.js
    console.log("Ahoj");
    ```
    

**8. Jaké přípony mohou mít externí soubory u JavaScriptu?**

**`.js`** (např. `script.js`)
**`.mjs`** (Module JavaScript)
