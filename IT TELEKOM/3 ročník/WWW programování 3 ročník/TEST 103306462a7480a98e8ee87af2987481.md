**Internet** je globální síť propojených počítačů, která umožňuje komunikaci a sdílení informací po celém světě. Název "Internet" je zkratkou anglického výrazu "inter-network", což v překladu znamená "mezi-síť". Tedy síť sítí.

## Jaké služby Internet poskytuje?

Internet nabízí širokou škálu služeb, například:

- **Světový web (World Wide Web):** umožňuje přístup k miliardám webových stránek s různým obsahem.
- **Elektronická pošta:** slouží k zasílání a přijímání zpráv. **(e-mail)**
- **Videohovory:** umožňují videokonference a komunikaci tváří v tvář. **(VoIp)**
- **Streamingové služby:** umožňují přehrávání hudby, filmů a videí online. **(UDP)**
- **HTTP:** Hypertext Transfer Protocol – protokol pro přenos hypertextových dokumentů (webových stránek).
- **FTP:** File Transfer Protocol – protokol pro přenos souborů.
- **SMTP:** Simple Mail Transfer Protocol – protokol pro odesílání e-mailů.
- **POP3:** Post Office Protocol version 3 – protokol pro příjem e-mailů.
- **IMAP:** Internet Message Access Protocol – další protokol pro příjem e-mailů, umožňuje pracovat s e-maily na serveru.
- **DNS:** Domain Name System – systém pro převod názvů domén na IP adresy.
- **SSH:** Secure Shell – protokol pro zabezpečený vzdálený přístup.
- **Telnet:** Protokol pro nezabezpečený vzdálený přístup.

## Co jsou to webové standardy a která organizace je navrhuje?

**Webové standardy** jsou soubor pravidel a specifikací, které určují, jak by měly být webové stránky vytvářeny a zobrazovány v různých prohlížečích. Jejich cílem je zajistit jednotný vzhled a chování webových stránek napříč různými zařízeními a platformami.

Hlavní organizací, která navrhuje a udržuje webové standardy, je **World Wide Web Consortium (W3C)**.

## Co je to značkovací jazyk?

**Značkovací jazyk** je systém pro strukturování a formátování textu. Pomocí speciálních značek (tagů) se označují jednotlivé části textu a definuje se jejich význam a vzhled.

## Popište vyvol jazyka HTML a uveďte jednotlivé verze značkovacího jazyka.

**HTML (HyperText Markup Language)** je základní značkovací jazyk pro vytváření webových stránek. Pomocí HTML tagů se definuje struktura dokumentu, nadpisy, odstavce, obrázky, odkazy a další prvky.

**Verze HTML:**

- **HTML 2.0:** První široce přijatá verze HTML.
- **HTML 3.2:** Rozšíření o nové prvky a atributy.
- **HTML 4.0:** Důležitá verze, která zavedla mnoho nových funkcí a zlepšila přístupnost.
- **XHTML:** Přechodná verze mezi HTML 4 a HTML5, která se snažila o větší přesnost a kompatibilitu s XML.
- **HTML5:** Přinesla mnoho nových prvků a funkcí, jako je video, audio, canvas a lepší podporu pro mobilní zařízení.

## Vyjmenujte a popište jednotlivé webové standardy.

Kromě HTML existují i další důležité webové standardy, například:

- **CSS (Cascading Style Sheets):** Jazyk pro formátování vzhledu webových stránek. Odděluje obsah od vzhledu, což umožňuje snadnější úpravy designu.
- **JavaScript:** Skriptovací jazyk pro přidávání interaktivních prvků na webové stránky.
- **DOM (Document Object Model):** Rozhraní pro programové manipulace s dokumentem HTML.
- **XML (eXtensible Markup Language):** Značkovací jazyk pro vytváření vlastních značek a struktur.
- **SVG (Scalable Vector Graphics):** Formát pro vektorovou grafiku na webu.
- SGML (Standard Generalized Markup Language – „univerzální značkovací metajazyk“)

Je standardní jazyk určený k formálnímu popisu struktury dokumentů. Je definován v normě ISO 8879 z roku 1986.

SGML je komplexní jazyk poskytující mnoho značkovacích syntaxí, ale jeho složitost brání většímu rozšíření.

## Dodržují se webové standardy v praxi? (odůvodníte)

Dodržování webových standardů není vždy dokonalé. Některé webové stránky mohou používat vlastní řešení nebo starší verze standardů, což může vést k problémům s kompatibilitou v různých prohlížečích.

**Důvody nedodržování:**

- **Kompatibilita s různými prohlížeči:** V minulosti byla kompatibilita mezi prohlížeči velkým problémem, což vedlo vývojáře k používání nestandardních řešení.
- **Tlak na rychlost a výkon:** Někdy se vývojáři rozhodnou obětovat standardy ve prospěch rychlejšího načítání stránky.
- **Neznalost standardů:** Někteří vývojáři nemusí být dostatečně obeznámeni s aktuálními standardy.

**Trendy:**

Přestože nedostatky stále existují, obecně se kvalita webových stránek zlepšuje. Moderní prohlížeče lépe podporují standardy a existuje stále větší tlak na vytváření přístupných a kompatibilních webových stránek.

## Jaké jsou výhody webových standardů?

- **Zlepšená kompatibilita:** Webové stránky vypadají a fungují podobně ve všech prohlížečích.
- **Lepší přístupnost:** Standardy usnadňují přístup k webovým stránkám pro osoby s různými typy postižení.
- **Snadší údržba:** Stránky vytvořené podle standardů jsou jednodušší na údržbu a aktualizaci.
- **Vyšší kvalita:** Standardy podporují vytváření profesionálně vypadajících a funkčních webů.

## Co je to DTD a k čemu slouží?

**DTD (Document Type Definition)** je soubor pravidel, který definuje strukturu dokumentu XML. DTD specifikuje, jaké elementy, atributy a jejich vztahy mohou být použity v dokumentu.

DTD funguje jako jakási šablona, která určuje strukturu daného dokumentu, vymezuje povolené prvky (elementy, atributy) a určuje tak standardy, kterými se dokument řídí.

## Co je hlavním úkolem DTD?

Hlavním úkolem DTD je zajistit, aby dokument XML byl dobře vytvořený a strukturovaný. DTD pomáhá ověřit, zda dokument splňuje všechna požadovaná pravidla a zda je validní.

## Uveďte příklady DTD pro Jazyk HTML, XHTML a HTML5.

**HTML:** HTML nemá striktní DTD, ale používá se doctype deklarace pro označení verze HTML. Například:

HTML

<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN" "[http://www.w3.org/TR/html4/loose.dtd](http://www.w3.org/TR/html4/loose.dtd)">

Při použití kódu [buďte obezřetní](https://www.notion.so/faq#coding).

**XHTML:** XHTML používá DTD pro zajištění větší přesnosti a kompatibility s XML. Například:

HTML

`<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN"
"http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">`

Při použití kódu [buďte obezřetní](https://www.notion.so/faq#coding).

**HTML5:** HTML5 nepoužívá DTD, ale používá doctype deklaraci pro označení verze HTML5.

HTML

`<!DOCTYPE html>`

Při použití kódu [buďte obezřetní](https://www.notion.so/faq#coding).

## Je deklarace Doctype case sensitive?

Deklarace DOCTYPE není ty ujo **case sensitive**, což znamená, že velká a malá písmena se nerozlišují.

**Poznámka:** V HTML5 je deklarace DOCTYPE velmi jednoduchá a stačí pouze `<!DOCTYPE html>`.
