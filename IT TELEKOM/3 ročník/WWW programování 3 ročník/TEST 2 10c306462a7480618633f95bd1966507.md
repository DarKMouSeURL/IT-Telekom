### Co je validace a k čemu slouží?

**Validace** je proces ověřování, zda je daný dokument (např. HTML, CSS) vytvořený podle stanovených pravidel a standardů. Její hlavní účel je zajistit, aby byl dokument správně interpretován všemi prohlížeči a zařízeními, což vede ke konzistentnějšímu zobrazení a lepšímu uživatelskému zážitku.

> Webové standardy (specifikace a doporučení vytvořená konsorciem W3C) nejsou normy, jimiž by se museli autoři bezpodmínečně řídit, zcela jistě však jde o zásady, které se vyplatí respektovat a jež jsou základním souhrnem důsledných, promyšlených a osvědčených postupů.
> 

### Online validace pro HTML

- **Webové adresy:**
    - **W3C Markup Validation Service:** [https://validator.w3.org/](https://validator.w3.org/)
        - Nejznámější a nejpoužívanější online validator HTML.
        - **Co lze validovat:** Celé HTML dokumenty, jednotlivé fragmenty kódu.
        - **Možné vstupy:** URL stránky, přímý vstup kódu, nahrání souboru.
        - **Výstupy:** Detailní informace o nalezených chybách a varováních, návrhy na opravu.
            - validní
            - nevalidní

### Off-line validace pro HTML

- **Programy:**
    - **HTML Tidy:** Otevřený zdroj, dokáže opravovat chyby i formátovat kód.
    - PSPad - Microsoft
    - **Některé IDE** (např. NetBeans, Eclipse) mají vestavěnou podporu validace HTML.
    - Rozšíření pro Visual studio **HTML-HINT**
- **Rozšíření pro prohlížeče:**
    - **Web Developer:** Rozšíření pro Firefox a Chrome, které umožňuje mezi jinými funkcemi i validaci HTML.
- **Postupy:**
    - **Instalace programu:** Stáhněte a nainstalujte vybraný program, popřípadě stáhnout dodatek do VS.
- **Výstupy:**
    - Podobné jako u online validace: seznam chyb, varování a návrhy na opravu.
    - validní
    - nevalidní

### Co je to W3C?

**W3C** (World Wide Web Consortium) je mezinárodní konsorcium, které se zabývá vývojem webových standardů. Jeho cílem je vytvořit otevřené standardy, které umožní dlouhodobý růst a vývoj webu.

### Jaké jsou činnosti W3C?

- **Vývoj standardů:** Vytváření specifikací pro jazyky jako HTML, CSS, XML atd.
- **Vzdělávání:** Organizace konferencí, workshopů a poskytování dokumentace.
- **Spolupráce s průmyslem:** Zapojení společností do tvorby standardů.
- **Podpora přístupnosti:** Zajištění, aby web byl přístupný všem uživatelům, včetně osob se zdravotním postižením.
