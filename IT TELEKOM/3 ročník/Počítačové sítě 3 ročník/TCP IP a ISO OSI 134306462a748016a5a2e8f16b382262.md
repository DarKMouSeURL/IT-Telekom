# TCP/IP a ISO/OSI

| RM ISO/OSI | PDU | Adresa | Protokoly |
| --- | --- | --- | --- |
| (L7) Aplikační | data | X (Žádné) | DNS, HTTP, FTP, TFTP, |
| (L6) Prezentační | data | X (Žádné) | POP3, telnet, SSH, SMTP |
| (L5) Relační | data | X (Žádné) | DHCP a další |
| (L4) Transportní | segment, datagram | Porty | TCP, UDP |
| (L3) Síťová | paket | IP | IPv4 (32 bit), IPv6 (128 bit) |
| (L2) Linková | frame (rámec) | MAC | Ethernet, Wi-Fi |
| (L1) Fyzická | bit | X (Žádné) | Ethernet, Wi-Fi |

Vrstva síťového přístupu = HW závislá vrstva.

RM ISO/OSI = Referenční model ISO/OSI

// PAT - port address translating.
