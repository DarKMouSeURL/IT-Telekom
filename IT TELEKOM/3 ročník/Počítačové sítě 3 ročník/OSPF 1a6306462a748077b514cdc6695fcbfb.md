- **Open Shortest Path First (OSPF)** je link-state směrovací protokol, který byl vyvinutý jako náhrada protokolu RIP
    - OSPFv2 aktualizována na dnešní podobu, [RFC 2328](https://www.rfc-editor.org/rfc/rfc2328.html).
    - OSPFv3 pro IPv6, [RFC 2740](https://datatracker.ietf.org/doc/html/rfc2740).
- **Zapouzdření zprávy protokolu OSPF:**
    - Datová část OSPF zprávy obsahuje jeden z pěti typů OSPF paketu.

## **OSPF Packet Types**

- **0x01 Hello**
    - pro vytvoření a udržení sousedství
- **0x02 Database Description (DD)**
    - szenam linek
- **0x03 Link State Request**
    - žádost další info o lince
- **0x04 Link State Update**
    - odpověď na 0x03, posílají se info o lince
    - může mít 11 různých typů 0x05
- **0x05 Link State Acknowledgment**
    - potrzení o přijetí 0x04

## **OSPF paket**

| Data Link Frame Header | IP Packet Header | OSPF Packet Header | OSPF Packet Type-Specific Data |
| --- | --- | --- | --- |
|  |  | OSPF zpráva | OSPF zpráva |
|  | IP paket | IP paket | IP paket |
| Ethernetový rámec | Ethernetový rámec | Ethernetový rámec | Ethernetový rámec |

## Router ID

- je to IP adresa
1. ip adresa nastavena příkazem
    
    ```json
    R7(Config-router)#router-id 1.2.3.9
    ```
    
2. pokud není nastavena ip adresa
    1. nastaví se na nejvyšší IP adresu na rozhraní Loopback
3. pokud není loopback
    1. nastaví se na nejvyšší IP adresu na aktivním rozhraní
