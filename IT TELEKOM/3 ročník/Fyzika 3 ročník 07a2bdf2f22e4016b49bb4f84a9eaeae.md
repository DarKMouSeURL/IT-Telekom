# Obsah učiva

- **opakování**
- **optika**
- **vlnové vlastnosti světla:**
    - zdroje světla, šíření a rychlost světla
    - optické prostředí, index lomu
    - frekvence a vlnová délka světla
    - spektrum elektromagnetického záření
    - záření infra-red, ultra-violet, rentgen
    - odraz a lom světla, úplný odraz
    - Disperze světla
    - interferenční jevy
    - ohybové jevy
- **Zobrazení zrcadlem a čočkou:**
    - zobrazení rovinným a kulovým zrcadlem
    - čočky jako zobrazovací soustavy
    - lidské oko
    - optické přístroje - lupa, mikroskop, dalekohled
- **Kvantová optika:**
    - vnější fotoelektrický jev
    - Einsteinova rovnice
    - Dvojí povaha světla
- **Fotometrie:**
    - fotometrické veličiny
- **Fyzika atomu**
- **Fyzika elektronového obalu**
    - modely atomu
    - elektronový obal atomu, kvantování energie
    - kvantově mechanický model atomu vodíku
    - spektrum atomu vodíku, laser
    - využití emise záření
    - fyzika atomového jádra
    - stavba atomového jádra, nukleony
    - radioaktivita
    - řetězové reakce, jaderné reaktor
    - jaderná energie a její využití, biologické účinky záření
- **Vesmír**
    - sluneční soustava, hvězdy a galaxie
