# funkce

1. sdělná
2. přesvědčovací
3. získávací
4. zábavná

# Charakteristika publicistického projevu

- psaná publicistika
    - Noviny, časopisy, internet media, teletext
- Mluvená publicistika
    - Zpravodajské relace, diskusní pořady, reportáže, cestopisné dokumenty

# Znaky

1. Veřejnost, oficiálnost
2. Připravenost, promyšlenost
3. aktuálnost, pravdivost, rychlost
4. působivost
5. přesvědčení

# Jazykové prostředky

- spisovný jazyk - knižní(výjimečně) i hovorový
- hledání nových **neotřelých pojmenování**
    - **Aktualizace** - upoutat pozornost adresáta (titulek)
        - z **aktualizovaných** výrazů → **automatické** výrazy
    - **Automatizace** - podporuje rychlost a úspornost vyjádření

# stavba publicistického textů

- texty musí mít **logickou výstavbu**
    - obrácená pyramida
    - delší texty mohou být rozděleny na menší části pomocí **mezititulků**
        
        ### **TITULEK**
        
        - jazykově náročné
        - konktrétně, stručné
        - mohou jen naznačovat obsah textu
        - grafická úprava - velikost, typ a řez písma, barva
