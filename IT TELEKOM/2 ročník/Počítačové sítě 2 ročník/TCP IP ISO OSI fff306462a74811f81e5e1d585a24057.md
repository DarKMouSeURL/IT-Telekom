| **TCP/IP** | **Datové Jednotky** | Adresy |
| --- | --- | --- |
| **Aplikační** | DATA |  |
| **Transportní** | SEGMENT | PORT (zdrojový)
(cílový)

| **Síťová** | PACKET | IPv4, IPv6 |

| **Síťové rozhraní (Fyzické)** | BIT |  |
