# Přímé a nepřímé směrování

| Přímé směrování | NEpřímé směrování |
| --- | --- |
| v LAN síti | vzdálené připojení |
- Porovnávají se IP start a destination
    - pokud se liší použije se NEpřímé směrování
    - pokud jsou stejné tak se použije přímé směrování
- poslední seskupení čísel se neporovnávají
