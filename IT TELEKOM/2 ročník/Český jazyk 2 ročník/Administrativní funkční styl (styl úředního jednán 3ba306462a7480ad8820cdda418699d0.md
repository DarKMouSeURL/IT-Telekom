# Administrativní funkční styl (styl úředního jednání)

- styl informativní a věcné komunikace s úřady
- je zaměřena na fakta a jejich sdělení
- ovlivňuje a řídí činnost adresáta

# Znaky a požadavky

- věcné vystižení, srozumitelnost, stručnost
- předepsané normy
- psané, připravené a promyšlené
- **objektivnost**
- věcná správnost
- jazyková správnost
- grafická přehlednost

# Funkce

- **řídicí** (směrnice, nařízení, zákony)
- **odborně sdělná** (zpráva, sdělení, úřední dopis)
- **správní** (žádost, protokol)

# Formy

- převážně psaná
- připravená a promyšlená
- struktura věcná nebo heslovitá

# Jazykové prostředky

- spisovný jazyk
- neutrální jazykové prostředky
- dodržování pravopisných norem
- ustálené formulace a šablony (”obracím se na Vás s žádostí”, “předem děkuji za kladné vyřízení”)
- zkratky, značky (ČR, spol., a.s.o., typ 521…)

## Úřední dopis – stížnost

**obsahuje tyto náležitosti:**

- adresa adresáta/instituce
- datum
- oslovení
- podpis
- adresa odesílatele
