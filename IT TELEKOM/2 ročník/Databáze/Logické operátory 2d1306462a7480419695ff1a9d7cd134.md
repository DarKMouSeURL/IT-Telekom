# Logické operátory

- Slouží k tvorbě logických výrazů (podmínek)
- Využíváme např. v podmíněných příkazech či při omezeních

# **Logický operátor AND**

- Binární operátor
- **Pokud** mají oba testované operandy hodnotu **TRUE**, celkový výsledek je **TRUE**
- **Pokud** má kterýkoli z operandů FALSE, celkový výsledek je **FALSE**

```sql
SELECT * FROM zamestnanec
WHERE jmeno = 'Jan' AND prijmeni = 'Novak';
```

# **Logický operátor OR**

- Binární operátor
- **Pokud** má kterýkoli testovaný operand hodnotu **TRUE**, celkový výsledek je **TRUE**
- **Pokud** mají oba operandy hodnotu FALSE, celkový výsledek je **FALSE**

```sql
SELECT * FROM zamestnanec
WHERE jmeno = 'Jan' OR prijmeni = 'Novak';
```

# **Logický operátor NOT**

- Unární operátor
- Operand s hodnotou **TRUE** převádí na hodnotu **FALSE**
- Operand s hodnotou **FALSE** převádí na hodnotu **TRUE**

```sql
SELECT * FROM zamestnanec
WHERE  NOT(jmeno = 'Jan');
```

```sql
SELECT * FROM zamestnanec
WHERE  jmeno != 'Jan';
```
