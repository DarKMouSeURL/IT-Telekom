# Další funkce

# **Convert()**

- Převede hodnotu na zadaný datový typ nebo sadu znaků
- Poodbné CAST()

```sql
SELECT CONVERT("2022-01-01", DATE);            //2020-01-01
```

# **DATABASE()**

- Vrátí aktuální název databáze
- Když není vrátí NULL či ""

```sql
SELECT DATABASE();
```

# **IF()**

- Má tři části
    - Podmínka
    - Výzva 1 (if)
    - Výzva 2 (else)
    
    ```sql
    SELECT IF(500 < 1000, 5, 10);             //5
    ```
    

# **IFNULL()**

- Má pouze 2 části
    - Výzva 1
    - Výzva 2
- Pokud výraz 1 == NULL, použije se výraz 2
- Jinak se použije výraz 1

```sql
SELECT IFNULL("Ahoj", "teleinfromatika.eu");          //"Ahoj"
```

# **ISNULL()**

- Má pouze 1 výraz
- Když je výraz NULL, vrátí 1
- Když ne vrátí 0

```sql
SELECT ISNULL(NULL);         //1
```

# **LASTINSERTID()**

- Vrátí poslední id které bylo upraveno nebo přidáno

```sql
SELECT LAST_INSERT_ID();       //7
```

# **NULLIF()**

- Porovnává dva výrazy
- Pokud jsou stejné vrátí NULL
- Jinak je vrácen první výraz

```sql
SELECT NULLIF(25, 25);     //NULL
```

# **USER()**

- Vrátí jmené uživatele a hostitele pro MySQL připojení
- Stejné jako SESSION_USER() / SYSTEM_USER()

```sql
SELECT USER();           //„karel@U18-07.TELEINFORMATIKA.EU"
```

# **VERSION()**

- Vypíše aktuální verzi MySQL databáze

```sql
SELECT VERSION();         //8.0.32
```
