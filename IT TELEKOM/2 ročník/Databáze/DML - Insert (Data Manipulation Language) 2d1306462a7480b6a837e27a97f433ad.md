# DML - Insert (Data Manipulation Language)

# **Součásti je sada příkazů**

- **INSERT** - vkládání řádku do tabulky
- **UPDATE** - úprava existující řádků
- **DELETE** - mazání existujících řádků

```sql
INSERT INTO zamestnanec (jmeno, prijmeni, datum_narozeni, poznamka)
VALUSE('Petr', 'Novy', '1976-04-25', …. )
```
