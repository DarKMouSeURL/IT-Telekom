# Úvod do jazyka SLQ

- 70. Léta
- Vývoj relačních databázích
- Potřeba sady pro ovládání DB
- SEQUEL (Structured English Query Language)
- Později na SQL (Structured Query Language)
- Přistupování k datům v databázi
- Bez znalosti fyzické organizace dat
- Efektivní
- Snadné učení a použití
- Kompletní funkcionalita

# Funkcionalita

- Vytváření nahrazování a mazání DB
- Vkládání, úprava a mazání dat
- Získávání dat v DB
- Kontrola přístupu do DB
- Konzistence a integrita DB

# Podkategorie

1. DDL (Data Definition Language) - Definuje Databázové struktury
2. DML (Data Manipulation Language) - manipulace s daty (INSERT, UPDATE, DELETE)
3. DQL (Data Query Language) - získávání dat z DB
4. DCL (Data Control Language) - kontrola uživatelského přístupu do DB
5. TLC (Transactional Control Language) - řízení DB transakcí
