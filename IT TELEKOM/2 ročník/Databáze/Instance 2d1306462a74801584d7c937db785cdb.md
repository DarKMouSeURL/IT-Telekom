# Instance

- Slovo instance můžeme také přeložit jako **výskyt** nebo ztělesnění.
- Každá entita v sobě zahrnuje určitý počet svých instancí, tedy výskytů.
- Entita však sama o sobě není instancí.

# **Entita a atribut**

- Entitu považujeme za pomyslnou kategorii něčeho, o čem budeme zpracovávat data.
- Jaká data to budou, říkají atributy entit.

# **Entita a instance**

- Entita společně se svými atributy tvoří model (předpis či přípravu) pro v budoucnu vznikající instance.
