# DDL - CREATE TABLE

- Vytvoření tabulky v DB
- Nutné oprávnění **CREATE TABLE**

# **Základní příkaz**

- Název tabulky
- Název sloupců
- Datový typ a jeho velikost/přesnost
- Výchozí hodnoty (volitelné)
- Integritní omezení (volitelné)

```sql
CREATE TABLE zamestnanec(
id INT NOT NULL AUTO_INCREMENT,
jmeno VARCHAR(30) DEFAULT "" NOT NULL,
prijmeni VARCHAR(45) DEFAULT "" NOT NULL,
mzda DECIMAL(10,2) DEFAULT 0 NOT NULL,
poznamka TEXT
);
```


# **Omezení**

- Jednotlivým omezením je možno definovat nastavení
- Nastavení se týká dvou situací:
    - **ON UPDATE**
    - **ON DELETE**

# **Nastavení**

## **CASADE**

- Pří odstranění čí aktualizaci záznamu v nadřazené tabulce dojde k automatickému odstranění či aktualizaci všech závislých záznamu z podřízené tabulky

## **SET NULL**

- Při odstranění či aktualizaci záznamu v nadřazené tabulce dojde k automatickému nastavení všech závislých záznamů z podřízené tabulky na hodnotu NULL

## **RESTRICT**

- Pokud na záznam nadřazené tabulky odkazuje alespoň jeden záznam z libovolné podřízené tabulky, není možno nadřazený záznam smazat či upravit

## **NO ACTION**

- V systémech MySQL je NO ACTION stejné nastavení jako RESTRICT
- Bývá nastaven jako výchozí možnost

```sql
CREATE TABLE zamestnanec(
id INT DEFAULT 0 NOT NULL,
jmeno VARCHAR(30) DEFAULT "" NOT NULL,
prijmeni VARCHAR(45) DEFAULT "" NOT NULL,
mzda DECIMAL(10,2) DEFAULT 0 NOT NULL,
poznamka TEXT,
PRIMARY KEY (id),
FOREING KEY(oddeleni_id) REFERENCES oddeleni(id)
ON UPDATE CASCADE ON DELETE CASCADE
);
```
