# Historie databází

# **1960**

- Počítače začínají
- PC jsou menší, rychlejší a levnější
- Firmy můžou si dovolit PC

# **1970-1972**

- Edgar frank Codd
- Relační model database
- Data mohou jsou uložena jinde než v programu

# **1976**

- Petr Chen udělal **Entity Relationship Model** (EMR) pro databáze

# **1980**

- Jazyk **SQL** (My SQL, MariaDB …)
- Je standart, až dodnes

# **1990**

- Internet
- Konektory (WWW, internet, databáze)

# **2000**

- Database se rozvíjí
- Komerční weby (Yahoo, Google, Amazon…)

# **Od 2010**

- **Cloud Computing**
- Společnosti nabízejí (Microsoft, Oracle, Apple)
