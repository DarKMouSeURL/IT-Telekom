# DQL - SELECT

> **D**ata **Q**uery **L**anguage (DQL)
> 

> Příkaz **SELECT**
> 

```sql
SELECT * FROM tabulka;
SELECT jmeno, prijmeni, mzda FROM osoba WHERE id = 5;
```

- Slouží k výběru sloupců, z nichž mají být vybrána data
- Místo sloupců je možno použít symbol hvězdičky**(*)**
- Klíčovým slovem **FROM** volíme tabulka

# **Omezení výsledků pro SELECT**

## **Klauze WHERE**

- SELECT
- UPDATE
- DELETE

```sql
SELECT jmeno; prijemni FROM zamestnanec
WHERE id = 6;
```

## **Klauzule LIMIT**

- Specifikuje počet vrácených záznamů
- Výhodné u rozsáhlých tabulek
- Zapisuje se **na konci** příkazů **SELECT**

```sql
SELECT * FROM zamestnanec
LIMIT 100;
```

## **Operátor IN**

- Umožňuje specifikovat více **hodnot** v rámci klauzule WHERE
- Je to kratší varianta operátoru **OR**

```sql
SELECT * FROM zamestnanec
WHERE oddeleni_id IN (1,2,3);
```

## **DISTINCT**

- Slouží k výběru odlišných hodnot
- Zapisuje se hned za příkazem SELECT
- Příkaz SELECT takto vrátí pouze záznamy s různými(neopakující se) hodnotami

```sql
SELECT DISTINCT oddeleni_id FROM zamestnanec;
```
