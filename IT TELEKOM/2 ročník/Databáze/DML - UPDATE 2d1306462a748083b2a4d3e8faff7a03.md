# DML - UPDATE

- Slouží k aktualizaci (změně) existujících řádků v tabulce
- Syntaxe příkazů UPDATE pro modifikaci jednoho atributu.
    - **UPDATE** tabulka
    - **SET** sloupec1 = hodnota
    - **WHERE** podmínka;
- Syntaxe příkazů UPDATE pro modifikaci více atributů
    - **UPDATE** tabulka
    - **SET** sloupec_1 = hodnota, …. Sloupec_N = hodnota
    - **WHERE** podmínka;
