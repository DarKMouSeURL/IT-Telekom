# Databázové modely

# **Typy**

- Hierarchický model
- Síťový model
- Objektově orientovaný
- Flat File
- **Relační**

## **Hierarchický model**

- stromová struktura
- entita má jednoho předka a může mít potomky

## **Síťový model**

- vylepšená stromová struktura
- entita má jednoho/více předků a potomků

## **Objektově orientovaný**

- organizace objektů
- používá se i v programování

## **Flat File:**

- data jsou v souboru "**Flat File"**
- záznamy dodržují formát
- nejsou žádné vztahy mezi záznamy
- TXT, CSV

## **Entita:**

- Cislo_zamestnanec,jmeno,prijmeni
- 001, Petr,Nová

## **Relační model:**

- organizované pomocí tabulek

### **organizace:**

- tabulka = entita
- sloupce = atributy
- řádky = instance
- **vychází z matematického modelu**
