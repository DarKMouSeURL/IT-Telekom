# Vztahy mezi entitami

- **asociace** mezi entitami
- v relačních dat. mají definované vztahy
- vztahy jsou obousměrné
- vztah mezi "kniha" a "autor"

# **Grafické vztahy**

- zapisují se diagramy (**ERD**)
- **E**ntity **R**elationship **D**iagram / Entitně vztahový diagram
- Entita je obdélník
- název entity je uvnitř nebo nad
- vztahy jsou vyjádřeny čarami

# **pojmenování vztahů**

- pojmenováváme vztahy
- může být v češtině
