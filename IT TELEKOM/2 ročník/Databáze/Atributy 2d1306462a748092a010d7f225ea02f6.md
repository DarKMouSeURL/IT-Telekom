# Atributy

<aside>
💡

atribut = **vlastnost** (property)

</aside>

- používá se i v programování, weby
- návaznost s **entitami**
- entita **má** atributy
- když není atributy, nejsou entity

# **příklady**

- id
- jmeno
- prijmeni
- nazev

# **pravidla pro název atribut:**

1. v jednotném čísle
2. žádná diakritika
3. snake_case, camelCase, PascalCase
4. jiný název než entita
5. atribut může být povinný/nepovinný
