# ISO/OSI TCP/IP

| **ISO** | PDU | **TCP/IP** | služby |
| --- | --- | --- | --- |
| **aplikační** | data | **aplikační** | DNS, DHCP, FTP, HTTP, DHCP, POP3 |
| **prezentační** | data | **aplikační** | MPEG, JPG, PNG, AES, IDEA, CHACHA |
| **relační** | data | **aplikační** | - |
| **transportní** | segment, datagram | **transportní** | TCP, UDP |
| **síťová** | packet | **síťová/network** | IPv4, IPv6 |
| **linková** | rámec | **network access** | Ethernet, PPP, DSL |
| **fyzické** | bit | **network access** | Ethernet |
